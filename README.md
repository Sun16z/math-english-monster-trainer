# 國英數自然 Monster Trainer

國小二下與五下期末複習用的可愛寵物答題遊戲。孩子可以在糖果世界闖關，答國語、英語、數學、自然題目，答錯會留在同一題訂正到答對，答對後攻擊、收服、餵食與培養寵物。

固定網站：

- GitHub Pages: https://sun16z.github.io/math-english-monster-trainer/

## 目前內容

- 國語、英語、數學、自然四科題庫與自動出題。
- 二下與五下期末常見範圍，五下數學包含百分率、公噸、公頃、公畝、平方公里、公尺等換算。
- 五下自然包含植物世界面面觀、空氣與燃燒。
- 英語題支援瀏覽器語音朗讀與跟讀提示。
- WebAudio 音效、連擊、傷害數字、收服動畫、孵蛋、寵物三階進化。
- 本機帳號登入，孩子名字與家庭代號會綁定各自的關卡、分數、食物、圖鑑與寵物進度。
- 完整寵物圖鑑，收齊後會顯示 6/6；可選擇任一已收服寵物餵食培養。
- 答對題目會永久建造方塊別墅，依序放置草地方塊、橡木門、玻璃窗、屋頂磚、家具、廚房、廁所、浴缸、泳池等方塊建材，答越多房子越完整。
- Three.js 3D 糖果星球與 voxel 方塊屋場景，寵物會住進房子裡，在客廳、窗邊與房間中自然走動，仍可點擊互動。
- 手機與桌機響應式介面。

## 本機開發

```bash
npm ci
npm run dev
```

## 驗證

```bash
npm test
npm run build
```

## 隱私

遊戲沒有後端資料庫。帳號、學習進度、寵物、食物、關卡與設定都存在目前瀏覽器的 localStorage，換裝置或清除瀏覽器資料後會重新開始。若要跨手機同步，可以在此版本上接 Firebase 或 Supabase。
