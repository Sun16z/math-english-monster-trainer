# 國英數自然 Monster Trainer Implementation Log

日期：2026-06-10

## 審查與實作計劃

1. 參考站偵察：確認玩法、技術、畫面結構。
2. Repo 掃描：選定獨立專案位置，避免干擾既有工作。
3. 架構定稿：分離題庫、遊戲狀態、畫面呈現。
4. 視覺概念：建立原創怪物與雙科訓練 UI 方向。
5. 第一版可玩：數學 / 英語題目、四選一、生命、分數、重開。
6. 怪物節奏：血量、波次、收集、命中回饋。
7. 英語題型：中英對照、拼字、句子填空。
8. 數學題型：加、減、乘、除、缺漏等式。
9. UI 打磨：桌機 / 手機響應、HUD、動畫與可讀性。
10. 品質驗證：測試、建置、瀏覽器互動、截圖檢查。

## 進度

- Round 1：參考站為 React/Tailwind 單頁遊戲，核心是怪物收集加答題訓練。
- Round 2：新增獨立資料夾 `math-english-monster-trainer`。
- Round 3：採用 React + Vite，題庫本機化，無外部 AI 或授權角色依賴。
- Round 4：生成視覺概念圖，存於 `docs/design-concept.png`。
- Round 5：完成遊戲邏輯、主畫面、樣式和 Node 測試初稿。
- Round 6：修正混合模式科目輪替，加入題目序號避免偏科。
- Round 7：瀏覽器開啟成功，補上 SVG favicon 消除 404 噪音。
- Round 8：修正戰鬥紀錄重複 key，避免 React 更新警告。
- Round 9：調整桌機主遊戲區高度，減少按鈕聚焦後的垂直捲動。
- Round 10：加強怪物漸層、森林層次、左欄統計和答案按鈕色彩。
- Round 11：改成二下 / 五下期末複習，科目新增國語，錯題必須訂正到答對，加入 WebAudio 音效。
- Round 12：新增 `docs/curriculum-scope.md`，記錄二下 / 五下三科內建大綱與題庫假設。
- Round 13：補上國英數命名與課綱來源連結，讓文件和畫面一致。
- Round 14：重做音效引擎，改為共用 AudioContext、每次互動主動 resume，新增「試聽」按鈕與播放狀態。
- Round 15：加入 HTMLAudioElement + WAV data URL fallback，並替播放 promise 加 timeout，避免瀏覽器擋音效時 UI 沒反應。
- Round 16：音效被瀏覽器擋住後，暫停答題自動重試，只在使用者按「試聽」或重新開啟音效時再解鎖。
- Round 17：英文題新增口說練習，題庫帶安全朗讀文字與答對後跟讀文字，畫面加入自動朗讀、念題目、念選項、跟讀答案。
- Round 18：參考 GitHub 上 BrainRush 的錯題本 / 本機資料、Magic English Buddy 的 TTS 跟讀、English Practice App 的 shadowing / spaced repetition，新增錯題回鍋排程。
- Round 19：查核台灣五下數學題庫方向，擴充百分率題庫與大單位換算題庫，包含公噸、公頃、公畝、平方公里、平方公尺、公尺。
- Round 20：查核五年級自然「植物世界面面觀」與「空氣和燃燒」範圍，新增自然科、植物題庫、燃燒題庫，並讓綜合模式輪替四科。
- Round 21：新增原創小芽寵養成，收服後有隨機特殊裝飾，答題與再次收服會累積經驗、升級、變大，收藏欄和場上隊友會呈現成長狀態。
- Round 22：新增動態寵物與餵食系統，寵物會呼吸、眨眼、擺尾、餵食跳躍咀嚼；答題表現會掉落小果實、奶油蛋糕、金色果實、星糖蛋糕，高分和連擊可取得更高階食物。
- Round 23：依本機 Game UI / Design Taste / Redesign skills 優化可愛互動，新增事件化音效、連擊音、再試提示音、升級音、稀有點心音、英文朗讀提示音；答對、答錯、收服、升級、餵食會出現短暫星光或點心特效，英文口說時夥伴會做說話動作。
- Round 24：新增原創黑月兔帽系與雲耳小狗系寵物，前兩隻收服寵改為「黑月咪兔」與「雲朵耳寶」；場上對手與身邊夥伴都可點擊互動，會觸發摸摸音效、跳躍 / 打招呼動作、愛心特效、提示槽回饋與鍵盤操作 aria 標籤。

- Round 25（2026-06-11）：修正題庫選項未洗牌的問題——原本國語、自然題的正確答案永遠在第一個選項；同時修正 makeRng 種子混合不足造成的抽題集中偏差。
- Round 26（2026-06-11）：題庫大擴充——國語二下 6→30 題、五下 6→31 題；英語二下 6→27、五下 6→27 個單字句型；自然二下 6→22 題、五下 14→27 題。
- Round 27（2026-06-11）：數學出題擴充——二下新增錢幣計算、分裝、數的大小比較；五下新增異分母分數加減、約分、通分比大小（共 16 種題型），新題型以 6000 次抽樣驗算全數正確。
- Round 28（2026-06-11）：怪物陣容改為「黑月兔系＋雲朵狗系」兩大原創家族（保留原 id 不影響舊存檔）：黑月咪兔、莓果咪兔、紫夜咪兔／雲朵耳寶、奶茶耳寶、星空耳寶；SVG 漸層改用 color-mix 依各怪物配色自動衍生。

- Round 29（2026-06-11）：新增寵物三階段進化（幼年→進化→究極，各有專屬名稱如黑月咪兔→黑月魔法兔→黑月女王兔），進化外觀加光環、星火、皇冠 SVG 層，答題升級與餵食升級都會觸發全螢幕進化動畫。
- Round 30（2026-06-11）：強化打擊感——答對出現飛出的傷害數字（連擊有加成標示）、畫面震動、收服時星星球從天而降搖三下＋光圈擴散＋「收服成功！」。
- Round 31（2026-06-11）：新增扭蛋孵蛋系統——答題表現掉神秘蛋／閃亮蛋／彩虹蛋，答對加溫，孵出薄荷／櫻花／星彩／黃金四種稀有變色皮膚（可孵出未收服的新夥伴直接入圖鑑），皮膚經升級與存檔不會遺失。
- Round 32（2026-06-11）：改為冒險地圖關卡制——糖果世界六關（月光糖果屋→星空鞦韆園），每關 5 波、第 5 波 BOSS（血量 1.55 倍、紅色血條與 BOSS 標籤），過關依錯題數拿 1-3 星，逐關解鎖，進度存本機。
- Round 33（2026-06-11）：戰場改為 CSS 3D 視差場景（preserve-3d 三層：飄雲星光／遠山／樹木水晶），場景色調隨關卡怪物配色變化，BOSS 波天空變色。
- Round 34（2026-06-11）：修正 SVG 漸層 id 撞名（同畫面兩隻同種怪物會吃到彼此顏色），改用 useId per-instance 漸層；vite.config 改吃 PORT 環境變數方便預覽工具。
- Round 35（2026-06-11）：瀏覽器實測完整流程——地圖選關→答題→傷害／收服→撿蛋→孵化彈窗→BOSS 戰→過關星星→解鎖下一關→餵食進化動畫，18 項單元測試全數通過。
